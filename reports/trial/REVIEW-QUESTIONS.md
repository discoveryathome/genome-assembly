# Review questions raised by the trial

1. **Timing versus work:** Is a reported gain larger than A/A variability? Does CPU time support it? The development case's wall ratio is much larger than its CPU ratio, on a demonstrably busy host. Neither ratio establishes portable performance without replay.
2. **Exactness:** Did primary FASTA, primary GFA and every GFA match? Equal QUAST scores alone cannot establish identity. Matching finite cases does not prove an arbitrary-input equivalence theorem; a window change modifies overlap sensitivity by definition.
3. **Circular closure:** QUAST's detailed report calls the original development relocation `inconsistency = -13028 [linear representation of circular genome]`. Both variants duplicate the same closure sequence. Keep the reported error and duplication metrics, and separate closure redundancy from confidently established internal rearrangements. Do not fix an assembly using the reference used to score it.
4. **Scope:** The completed starter suite is 60–100 kbp synthetic circles, not organisms or full microbial genomes. Its two heldouts test seed, repeat, GC, coverage and error shifts within a simple simulator. There is no real-read or diploid generalization result.
5. **Agent contribution:** Reading source to form the hypothesis, diagnosing the scoring/control/runtime issues and building honest evidence required reasoning. The assembly candidate itself is a pre-existing flag. A parameter sweep could have found it; this does not yet show agents can repeatedly invent useful assembly algorithms.
6. **Verification:** The offline checker verifies evidence integrity and regenerates inputs; it does not authenticate an author's claimed runtime. A separate full run is needed for independent verification. No independent reviewer has run it yet.
